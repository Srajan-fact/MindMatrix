# MindMatrix 🚀

A collection of Android, Kotlin, and Jetpack Compose projects, assignments, and internship tasks completed as part of the MindMatrix Internship Program. This repository showcases practical implementations of Android development concepts, UI design, navigation, state management, and real-world app features.

---

## 📌 About

This repository contains multiple Android development projects and codelabs built using modern Android technologies. The projects focus on:

- Jetpack Compose UI
- Navigation Components
- MVVM Architecture
- State Management
- Firebase Integration
- API Handling
- Kotlin Programming
- Material Design
- Real-world Android App Development

The repository is actively updated with internship tasks, experiments, and learning projects.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Android Studio
- Kotlin SDK
- Git

### Clone the Repository

```bash
git clone https://github.com/Srajan-fact/MindMatrix.git
```

### Open in Android Studio

1. Open Android Studio  
2. Click on **Open**  
3. Select the cloned repository folder  
4. Sync Gradle and run the project
